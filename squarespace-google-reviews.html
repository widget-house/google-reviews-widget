THE PRACTICAL WORKFLOW

How to add Google Reviews to Squarespace

Start with the Widget House installation-code guide ↗. Then follow the platform steps below.

  1. 01

    Prepare the right source

    Create a Google Reviews widget in Widget House. Confirm the business name and location, choose a layout, publish the widget, and copy the full installation code from Install.

  2. 02

    Choose the moment that matters

    Open the Squarespace page or post and select Edit. For a service business, use the section just before the contact or booking action. Avoid placing a large review grid above the page’s main offer.

  3. 03

    Add a Code block

    Add a block, choose Code, and set its type to HTML. Paste the complete generated snippet and turn Display Source off so visitors see the rendered widget.

  4. 04

    Save and check the public page

    Save your changes and view the page while logged out. Squarespace can suppress scripts during editing; use Preview in Safe Mode where available before treating an editor placeholder as a failed installation.

Check your own installation. These steps combine current platform documentation with the Widget House embed workflow. They are not a certification of every theme, site plan, or third-party script.

CHECK ONE THING AT A TIME

If something does not look right

I see the code instead of reviews.

Confirm that Display Source is off and the block type is HTML. Check that the whole embed was pasted without added quotation marks.

It is blank in the editor.

Check the logged-out public page and your plan’s script support. An editing placeholder alone does not establish whether visitors can see the widget.

The reviews section feels crowded.

Adjust the section width and spacing in Squarespace and the card layout in Widget House. Recheck with a long review on a narrow screen.

COMMON QUESTIONS

Squarespace embed questions

Is this a Squarespace Extensions listing?

This guide describes an embed installation. It does not represent an approved Widget House listing in the Squarespace Extensions marketplace.

Do I need site-wide Code Injection?

Start with a Code block on the page that needs reviews. Follow any separate loader instructions in your actual Widget House snippet; do not add duplicate loaders simply to make the block appear.

Can an AI assistant help me install the widget?

Yes, if it has access to your project or supported website editor. Give it the complete snippet from your own account and this guide, then ask it to verify the rendered result. The AI setup prompt provides a starting point.

Will the widget give my page Google review stars in search?

Do not assume that it will. Displaying reviews on a page and eligibility for search-result review features are separate matters. This guide does not promise rich results, higher rankings, or inclusion in AI answers. Read Google’s review-snippet guidance before adding review markup.
