GOOGLE REVIEWS BY WIDGET HOUSE

Use your published widget on a website.

This guide is for existing Widget House users who have already published a Google Reviews widget for their business. Give the Google Reviews by Widget House plugin its complete public Install code so it can check the supported code structure and prepare an integration for HTML, React, or Next.js.

Using Codex? Download the Google Reviews by Widget House plugin v0.1.1 (full ZIP). This GitHub download is separate from availability in the OpenAI Plugins Directory.

Before you begin

You need a published widget for the correct business and location, its public Install code, and access to the website project you want to edit. The plugin does not access your Widget House account or private projects, create or publish a widget, or edit a website by itself.

IN THIS GUIDE

01 / YOUR EXISTING WIDGET

Find the public Install code

  1. 1

    Open the published widget

    In your Widget House account, open the Google Reviews widget for the business and location you intend to show. Confirm that it is published.

  2. 2

    Copy the complete code

    Choose Install and copy the entire public installation snippet. Keep its widget ID and loader URL intact. The Widget House code guide shows the account-side steps.

A business name, Google Maps link, screenshot, or widget preview URL is not a substitute for the Install snippet.

02 / WORK WITH YOUR ASSISTANT

Provide the code and the destination

When using the plugin in ChatGPT or Codex, give your assistant the public Install snippet and identify the website project and page. For example:

“Add my published Widget House Google Reviews widget to this website. Use this Install code, place it on the contact page, and check the rendered result on desktop and mobile.”

The plugin can check whether the supplied code matches its supported structure and prepare framework-specific integration code. An assistant needs separate access to your website project to place that code and test the page. A structural check does not prove that a widget is live, belongs to a particular business, or displays reviews.

03 / WEBSITE FRAMEWORKS

Fit the integration to your project

HTML

Use the validated Install code in the intended page section. Keep the widget mount and loader together according to your site’s script-loading rules, and avoid loading the same script twice.

React

Use a component that mounts the widget in the browser. Follow the project’s existing loader convention, and check what happens when the component unmounts and returns.

Next.js

Render the widget in a client component after hydration. Check the initial page, a reload, and route navigation. Reuse any loader already present instead of adding a duplicate.

The supported Install format can change. If your current snippet differs from the plugin’s recognized format, check the current Widget House instructions; do not guess a replacement widget ID or script URL.

04 / CHECK THE ACTUAL PAGE

Confirm what visitors can see

  • Open the published website page and confirm the correct business and real reviews appear. A successful code check or loaded script alone is not enough.
  • Check the page at desktop and narrow mobile widths. Look for clipped cards, overflow, readable text, attribution, and working links.
  • In React or Next.js, navigate away and back. Confirm that one widget appears without duplicate mounts or loaders.
  • If the widget is blank, confirm that the widget is published, the full code is present, and the site allows the required script and frame. Report any browser error you can observe.

DATA HANDLING

Share only the public code

When your assistant calls the plugin, the connected tool receives the public Install code and website framework you provide to check the code’s structure and prepare integration code. It does not need your password, session cookie, private API key, or customer account data. Do not include those in the snippet or your prompt.

After installation, the widget running on your website contacts Widget House services to display reviews. That browser activity is separate from the plugin’s code check. Read the plugin privacy notice and the Widget House Privacy Policy for details.
