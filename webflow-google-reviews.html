THE PRACTICAL WORKFLOW

How to add Google Reviews to Webflow

Start with the Widget House installation-code guide ↗. Then follow the platform steps below.

  1. 01

    Prepare a responsive review layout

    Choose the business and layout in Widget House. Publish the widget, open Install, and copy the generated code. Make a note of the expected business name so your launch check can verify the source.

  2. 02

    Build the surrounding section

    In Webflow, create a reviews section with a heading and a container that follows the page’s spacing. Avoid a fixed-height wrapper that could crop longer reviews or a changing number of cards.

  3. 03

    Insert the Code Embed

    Open the Add panel, choose Code Embed, paste the complete Widget House snippet, and select Save & close. Keep the generated embed intact and avoid adding a second document structure around it.

  4. 04

    Preview, publish, and inspect

    A script may appear as a placeholder in the Designer. Check Preview and a published staging page, then verify the production page after publishing. Review narrow breakpoints and navigation back to the page.

Check your own installation. These steps combine current platform documentation with the Widget House embed workflow. They are not a certification of every theme, site plan, or third-party script.

DESIGN AROUND THE DECISION

An agency-built landing page

After the offer and service details, use a full-width reviews section to support the main call to action. A Grid suits a longer proof section; a Slider can fit a narrower layout. Let the real review content determine the height instead of forcing it into a fixed mockup.

CHECK ONE THING AT A TIME

If something does not look right

The Designer shows a placeholder.

Check Preview and the published staging URL. Some embedded scripts are represented by placeholders while editing.

Cards are clipped on mobile.

Inspect the surrounding container’s width, height, and overflow rules. Then adjust the widget layout and test a longer review.

It works on one page but not another.

Compare the embed and page settings. Check whether shared components added an extra loader or whether custom scripts report an error on the affected page.

COMMON QUESTIONS

Webflow embed questions

Do I need a Webflow App to use this workflow?

This is a Code Embed workflow. It does not claim a native Widget House Webflow App or an approved marketplace listing.

Where should I style the reviews?

Use Webflow for the page section, spacing, and surrounding content. Use Widget House for the options exposed by its review editor. Verify both together on the public page.

Can an AI assistant help me install the widget?

Yes, if it has access to your project or supported website editor. Give it the complete snippet from your own account and this guide, then ask it to verify the rendered result. The AI setup prompt provides a starting point.

Will the widget give my page Google review stars in search?

Do not assume that it will. Displaying reviews on a page and eligibility for search-result review features are separate matters. This guide does not promise rich results, higher rankings, or inclusion in AI answers. Read Google’s review-snippet guidance before adding review markup.
