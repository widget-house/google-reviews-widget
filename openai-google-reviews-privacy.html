GOOGLE REVIEWS BY WIDGET HOUSE

Plugin privacy notice.

This notice explains what happens to information sent to the Google Reviews by Widget House MCP tools when you use the integration through ChatGPT or Codex. It supplements the Widget House Privacy Policy, which covers accounts, published widgets, visitors to websites using those widgets, and your privacy rights.

The plugin is intended for customers with a Google Reviews widget already published for their own business. It needs only the widget's public Install code. Do not provide a password, private API key, payment information, or private customer data.

Information the tools receive

When your assistant calls a plugin tool, OpenAI sends the tool arguments to the Widget House-operated MCP service hosted on Cloudflare Workers:

  • Find setup instructions: no tool arguments.
  • Validate installation code: the text supplied in the installation-code field. A valid code snippet includes a public widget ID and Widget House script URL.
  • Prepare integration code: the supplied installation code and your selected framework: HTML, React, or Next.js.

If you put other text in the installation-code field, that text is sent to the MCP service for validation too. Cloudflare may also process network and security metadata, such as a connecting IP address, time, requested path, and client details.

How the information is used

The tools explain where an existing customer can find the public code for an already published widget, check whether supplied code matches the supported structure, and prepare code for a website project. Results return to OpenAI and can include the public widget ID, script URL, framework choice, generated code, and setup guidance.

The MCP tools do not sign in to your Widget House account, read private projects, fetch Google reviews or Google account data, create or publish a widget, edit or deploy a website, or process payments. A structural code check does not establish that a widget is live or belongs to a particular business.

Service providers and other recipients

OpenAI provides the ChatGPT or Codex interface, passes the selected tool request to our MCP service, and receives its result. OpenAI handles your conversation under its Privacy Policy. Cloudflare hosts and routes the MCP service and may process request and security metadata under its Privacy Policy. Widget House does not sell personal information.

After you install a widget on a website, that widget's browser requests to Widget House are a separate data flow covered by the main Widget House Privacy Policy and, where applicable, the website owner's notice.

Storage and retention

The MCP application processes tool arguments in memory for the request. Its code does not write the installation snippet or tool arguments to an application database, keep them for later application use, or intentionally log request bodies. Tool requests and responses may remain in your OpenAI conversation under OpenAI's controls and retention practices.

Cloudflare may separately retain network or security metadata according to its own policies. Widget House's main policy says that certain technical data we separately store for diagnostics and security may be kept for up to seven days, with longer retention where needed to investigate security issues, fraud, abuse, technical problems, or legal matters. That period is not a promise about Cloudflare's independently processed records.

Your choices and rights

  • You can choose not to call the plugin or provide installation code. Use only the public Install code from a widget published for your own business.
  • For information held in your OpenAI account or conversation, use OpenAI's available account and conversation controls.
  • For access, correction, deletion, or other questions about information held by Widget House, contact us using the email below. We may need to verify your identity, and rights depend on applicable law.

Who to contact
