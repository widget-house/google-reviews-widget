THE PRACTICAL WORKFLOW

How to add Google Reviews to WordPress

Start with the Widget House installation-code guide ↗. Then follow the platform steps below.

  1. 01

    Get your widget code

    In Widget House, select the business, customize Google Reviews, publish the widget, and open Install. Keep the original snippet so you can compare it with the saved page later.

  2. 02

    Open the intended page

    In the block editor, choose the page where reviews help a reader make a decision. Add a Custom HTML block in that section and paste the generated installation code into the HTML editor.

  3. 03

    Save and inspect what remains

    Update the page. If the widget does not appear, reopen the block and check whether a script or iframe tag was removed. On WordPress.com, confirm the paid plan and activated hosting features; its support guide explains the activation step.

  4. 04

    Check the page visitors receive

    View the published page while logged out. If your site uses a cache or script optimization, compare the result after its normal cache refresh and check for script errors before changing several settings at once.

Check your own installation. These steps combine current platform documentation with the Widget House embed workflow. They are not a certification of every theme, site plan, or third-party script.

CHECK ONE THING AT A TIME

If something does not look right

My script disappears after saving.

That points to HTML filtering or permissions. Check your hosting type and the account that saved the page before trying another embed.

I see the old design.

Check that the widget was republished and the correct snippet is on the page. Then check the WordPress or CDN cache using your site’s normal process.

The widget loads twice.

Look for the same embed in the page, a reusable block, and the theme. Keep the intended mount and follow the generated loader instructions.

COMMON QUESTIONS

WordPress embed questions

Is a dedicated WordPress plugin required?

This workflow uses a supported HTML embed area. This repository does not contain a native WordPress plugin or claim a WordPress.org directory listing.

Can I do this on a free WordPress.com site?

A script-based or iframe embed needs the capabilities described in the current WordPress.com support guide. Its paid-plan and hosting-feature requirements differ from ordinary text and HTML blocks.

Can an AI assistant help me install the widget?

Yes, if it has access to your project or supported website editor. Give it the complete snippet from your own account and this guide, then ask it to verify the rendered result. The AI setup prompt provides a starting point.

Will the widget give my page Google review stars in search?

Do not assume that it will. Displaying reviews on a page and eligibility for search-result review features are separate matters. This guide does not promise rich results, higher rankings, or inclusion in AI answers. Read Google’s review-snippet guidance before adding review markup.
